# 1. 물타기의 정의

## 1.1 물타기(Averaging Down)의 의미

물타기란, 투자자가 이미 보유하고 있는 주식의 가격이 매입가보다 하락했을 때, 더 낮은 가격에서 같은 종목을 추가 매수하여 전체 평균 매입 단가를 낮추는 투자 행위를 말한다.

예를 들어 다음과 같은 상황이다.

```text
1차 매수:
- 매수가: 10,000원
- 수량: 10주
- 투자금: 100,000원

현재 주가 하락:
- 현재가: 7,000원

추가 매수:
- 매수가: 7,000원
- 수량: 10주
- 추가 투자금: 70,000원

결과:
- 총 보유 수량: 20주
- 총 투자금: 170,000원
- 평균 매입 단가: 8,500원
```

이 경우 기존에는 주가가 10,000원까지 회복되어야 손익분기점에 도달했지만, 추가 매수 이후에는 평균 단가가 8,500원으로 낮아진다.

즉, 물타기의 표면적 목적은 다음과 같다.

```text
평균 매입 단가를 낮춘다.
손익분기점을 낮춘다.
반등 시 손실 회복 가능성을 높인다.
```

하지만 물타기는 단순히 손익분기점을 낮추는 계산 행위가 아니다. 잘못된 종목이나 잘못된 시점에서 물타기를 하면 손실 규모가 커지고, 회복 불가능한 투자 상태로 이어질 수 있다.

---

## 1.2 물타기의 본질

물타기의 본질은 “가격이 싸졌으니 더 산다”가 아니다.

물타기의 본질은 다음 질문에 답하는 것이다.

```text
이 종목은 지금 추가 매수를 해도 되는 상태인가?
```

즉, 물타기는 가격 자체보다 다음 요소를 종합적으로 판단해야 하는 문제다.

```text
1. 하락이 일시적인가, 구조적인가?
2. 회사의 펀더멘털이 유지되고 있는가?
3. 시장 전체 흐름이 회복 가능한 구간인가?
4. 기술적으로 하락이 멈추거나 둔화되고 있는가?
5. 거래량과 수급이 회복 신호를 보이고 있는가?
6. 상장폐지, 거래정지, 감사의견 거절 같은 치명적 위험은 없는가?
7. 추가 매수 후에도 감당 가능한 리스크 범위인가?
```

따라서 이 시스템에서 물타기는 “추가 매수 추천”이 아니라 “추가 매수 위험도 판단”으로 정의한다.

---

## 1.3 물타기의 장점

물타기는 조건이 맞을 경우 다음과 같은 장점을 가질 수 있다.

### 1. 평균 매입 단가 하락

추가 매수를 통해 기존 평균 매입 단가를 낮출 수 있다.

```text
기존 평균 단가 > 추가 매수가
→ 전체 평균 단가 하락
```

### 2. 손익분기점 하락

평균 단가가 낮아지면 기존보다 낮은 가격에서도 손실 회복이 가능해진다.

### 3. 우량 종목의 일시적 하락 활용

기업 가치가 유지되고 있고 시장 전체 하락이나 일시적 악재로 가격이 하락한 경우, 장기 관점에서 유리한 매수 구간이 될 수 있다.

### 4. 분할 매수 전략과 결합 가능

물타기는 한 번에 모든 자금을 투입하는 것이 아니라, 정해진 조건에 따라 나누어 매수하는 전략과 결합할 수 있다.

---

## 1.4 물타기의 위험성

물타기는 높은 위험을 가진 전략이다. 특히 하락 추세가 지속되는 종목에서 반복적으로 물타기를 하면 손실이 빠르게 커질 수 있다.

대표적인 위험은 다음과 같다.

### 1. 손실 확대

가격이 더 하락하면 추가 매수한 금액까지 손실 구간에 들어간다.

```text
기존 손실 + 추가 매수분 손실
→ 총 손실 금액 확대
```

### 2. 구조적 악재 종목에 대한 추가 투자

기업의 실적이 무너졌거나, 회계 문제가 있거나, 상장폐지 위험이 있는 종목에 물타기를 하면 리스크가 급격히 증가한다.

### 3. 자금 고갈

계속 하락하는 종목에 반복적으로 추가 매수하면 다른 투자 기회를 놓치고, 현금 비중이 사라질 수 있다.

### 4. 심리적 고착

물타기를 반복하면 “언젠가는 오르겠지”라는 기대가 강해져 손절 판단이 어려워진다.

### 5. 기회비용 증가

손실 종목에 자금이 묶이면서 더 좋은 투자 기회를 활용하지 못할 수 있다.

---

## 1.5 물타기와 불타기의 차이

물타기와 불타기는 모두 추가 매수 전략이지만 방향성이 다르다.

| 구분 | 설명 | 목적 |
|---|---|---|
| 물타기 | 하락한 종목을 추가 매수 | 평균 단가 하락 |
| 불타기 | 상승 중인 종목을 추가 매수 | 상승 추세 추종 |

물타기는 손실 중인 포지션에 자금을 더 넣는 전략이고, 불타기는 수익 중인 포지션에 자금을 더 넣는 전략이다.

따라서 물타기는 본질적으로 리스크 관리가 더 중요하다.

# 2. 시스템 개요

## 2.1 시스템 정의

본 시스템은 사용자가 보유 중인 주식 종목에 대해, 해당 종목이 추가 매수 즉 물타기를 검토할 수 있는 구간인지 판단하는 데이터 기반 리스크 분석 시스템이다.

시스템이 답해야 하는 핵심 질문은 다음과 같다.

```text
지금 이 종목을 추가 매수해도 되는가?
아니면 손실 확대 위험이 더 큰 구간인가?
```

이 시스템은 “무엇을 사야 하는가”를 알려주는 종목 추천 시스템이 아니다.

또한 “언제 매수하면 수익이 나는가”를 보장하는 수익 예측 시스템도 아니다.

이 시스템은 사용자가 이미 보유한 종목에 대해 다음 판단을 돕는 도구다.

```text
1. 추가 매수 검토 가능
2. 관찰 필요
3. 물타기 금지
4. 손절 또는 비중 축소 기준 점검 필요
```

---

## 2.2 시스템의 목적

본 시스템의 목적은 크게 다섯 가지다.

### 1. 감정적 물타기 방지

주가가 하락하면 투자자는 다음과 같은 감정적 판단을 하기 쉽다.

```text
너무 많이 떨어졌으니 이제 오르겠지.
평균 단가를 낮추면 금방 회복되겠지.
여기서 팔 수는 없으니 더 사야겠다.
```

이 시스템은 이런 감정적 판단을 줄이고, 데이터에 기반한 판단을 제공한다.

### 2. 손실 확대 리스크 차단

치명적 악재가 있거나, 시장 전체가 급락 중이거나, 종목의 하락 추세가 계속되는 경우에는 물타기를 막는 것이 중요하다.

이 시스템은 특히 다음과 같은 위험 구간을 조기에 식별하는 것을 목표로 한다.

```text
상장폐지 위험
거래정지
관리종목 지정
감사의견 거절
유상증자 또는 감자
영업손실 지속
지지선 이탈
기관·외국인 동시 순매도
시장 전체 급락
```

### 3. 추가 매수 판단 기준 표준화

투자자가 매번 다른 기준으로 판단하지 않도록, 점수와 등급 기반의 일관된 기준을 제공한다.

### 4. 분할 매수 전략 보조

추가 매수가 가능한 구간으로 판단되더라도 한 번에 모든 자금을 투입하지 않도록, 분할 매수 기준과 예산 배분 기준을 제공한다.

### 5. 손절 기준 명확화

물타기 후에도 주가가 다시 하락하거나 지지선을 이탈하면 손절 또는 비중 축소 기준을 점검해야 한다.

이 시스템은 추가 매수뿐 아니라 추가 매수 이후의 리스크 기준도 함께 제공한다.

---

## 2.3 시스템의 비목표(Non-Goals)

본 시스템은 다음 기능을 제공하지 않는다.

```text
1. 매수 추천
2. 매도 추천
3. 수익률 보장
4. 목표 주가 제시
5. 자동 매매 실행
6. 종목 추천
7. 투자 자문
8. 재무 상담
```

특히 API 응답, 화면 문구, README 문서에서 다음과 같은 표현을 사용하면 안 된다.

```text
지금 매수하세요.
무조건 오릅니다.
수익이 예상됩니다.
손실이 회복됩니다.
지금이 바닥입니다.
반드시 물타기하세요.
```

허용되는 표현은 다음과 같다.

```text
추가 매수 가능성을 검토할 수 있는 구간입니다.
관찰이 필요한 구간입니다.
추가 매수는 신중해야 하는 구간입니다.
위험 신호가 강해 비중 축소 또는 손절 기준 점검이 필요합니다.
본 결과는 투자 참고용 데이터 분석입니다.
```

---

## 2.4 시스템의 핵심 철학

이 시스템은 다음 철학을 따른다.

```text
1. 수익보다 리스크가 먼저다.
2. 기술적 지표보다 위험 이벤트가 먼저다.
3. 종목보다 시장이 먼저다.
4. 가격보다 추세가 먼저다.
5. 손실률보다 하락 원인이 먼저다.
6. 추가 매수보다 자금 관리가 먼저다.
7. 점수보다 치명적 리스크 필터가 먼저다.
```

즉, 어떤 종목의 RSI가 낮고 지지선에 가까워 보이더라도, 거래정지나 상장폐지 위험이 있다면 추가 매수 가능 구간으로 분류하면 안 된다.

# 3. 시스템 판단 구조

## 3.1 최종 판단 등급

시스템은 최종적으로 보유 종목을 다음 4단계로 분류한다.

| 등급 | 상태 | 의미 |
|---|---|---|
| A | 추가 매수 가능성 검토 구간 | 기술적·수급·시장·리스크 조건이 비교적 우호적 |
| B | 관찰 구간 | 반등 가능성은 있으나 추가 확인이 필요 |
| C | 물타기 금지 구간 | 하락 추세 지속 또는 리스크가 큰 상태 |
| D | 손절 또는 비중 축소 기준 점검 구간 | 구조적 악재 또는 치명적 위험 신호가 강한 상태 |

등급은 “투자 행동 명령”이 아니라 “리스크 상태 분류”다.

예를 들어 A 등급은 “매수하라”가 아니라 “추가 매수 가능성을 검토할 수 있는 조건이 상대적으로 우호적”이라는 의미다.

---

## 3.2 전체 판단 흐름

시스템은 다음 흐름으로 판단한다.

```text
1. 사용자 보유 종목 조회
2. 평균 매입가, 보유 수량, 현재가 기준 손익률 계산
3. 최근 가격 데이터 조회
4. 기술적 지표 계산 또는 조회
5. 수급 데이터 조회
6. 시장 데이터 조회
7. 뉴스/공시 위험 이벤트 조회
8. 1차 위험 필터 적용
9. 시장 상태 점검
10. 추세 점수 계산
11. 지지선 점수 계산
12. 거래량 점수 계산
13. 수급 점수 계산
14. 시장 점수 계산
15. 뉴스/공시 리스크 감점 적용
16. 총점 계산
17. A/B/C/D 등급 변환
18. 추가 매수 가능 예산 계산
19. 손절 기준 계산
20. 판단 사유 생성
21. 결과 저장
22. 사용자에게 결과 반환
```

---

## 3.3 판단 우선순위

시스템은 모든 데이터를 동일한 중요도로 보지 않는다.

판단 우선순위는 다음과 같다.

```text
1순위: 치명적 위험 이벤트
2순위: 시장 전체 흐름
3순위: 종목의 중단기 추세
4순위: 지지선과 거래량
5순위: 외국인·기관·개인 수급
6순위: 손실률
7순위: 분할 매수 가능 예산
```

이 우선순위가 중요한 이유는 다음과 같다.

- 손실률이 크다고 해서 무조건 물타기 구간은 아니다.
- RSI가 낮다고 해서 무조건 반등 구간은 아니다.
- 지지선 근처라고 해도 시장이 급락 중이면 위험하다.
- 기술적 지표가 좋아도 거래정지나 상장폐지 위험이 있으면 D 등급이어야 한다.

---

## 3.4 1차 위험 필터

1차 위험 필터는 점수 계산보다 먼저 적용된다.

아래 조건 중 하나라도 확인되면 기술적 점수와 무관하게 C 또는 D 등급으로 분류한다.

| 위험 조건 | 기본 처리 | 설명 |
|---|---|---|
| 거래정지 | D | 정상적인 매매가 불가능하므로 치명적 위험 |
| 상장폐지 위험 | D | 원금 회수 가능성이 크게 낮아지는 위험 |
| 관리종목 지정 | D | 시장에서 위험 종목으로 분류된 상태 |
| 감사의견 거절 | D | 회계 신뢰성 훼손 |
| 최근 감자 | D | 기존 주주 가치 훼손 가능성 |
| 횡령·배임 | C 또는 D | 규모와 영향에 따라 분류 |
| 최근 유상증자 | C 또는 D | 주가 희석과 수급 악화 가능성 |
| 영업이익 연속 적자 | C | 구조적 실적 악화 가능성 |
| 고점 대비 -60% 이상 하락 | C 또는 D | 단순 조정이 아닐 가능성 |
| 거래량 급감 후 지속 하락 | C | 시장 관심 이탈 가능성 |

# 4. 필요한 데이터 정의

## 4.1 데이터 카테고리

시스템은 다음 6가지 데이터 카테고리를 필요로 한다.

```text
1. 사용자 보유 종목 데이터
2. 종목 기본 정보 데이터
3. 가격 데이터
4. 기술적 지표 데이터
5. 수급 데이터
6. 시장 데이터
7. 뉴스/공시 리스크 데이터
```

실제 구현에서는 6가지라고 표현할 수도 있지만, 데이터 모델 관점에서는 종목 기본 정보와 사용자 보유 정보를 분리하는 것이 좋다.

---

## 4.2 사용자 보유 종목 데이터

사용자 보유 종목 데이터는 사용자가 어떤 종목을 어떤 가격과 수량으로 보유하고 있는지를 나타낸다.

| 필드 | 설명 | 예시 |
|---|---|---|
| user | 사용자 | request.user |
| stock | 종목 FK | 삼성전자 |
| stock_code | 종목 코드 | 005930 |
| stock_name | 종목명 | 삼성전자 |
| average_price | 평균 매입 단가 | 75000 |
| quantity | 보유 수량 | 10 |
| total_invested_amount | 총 투자금 | 750000 |
| current_price | 현재가 또는 최근 종가 | 69000 |
| loss_rate | 현재 손익률 | -8.0 |
| max_additional_budget | 추가 매수 가능 금액 | 1000000 |
| risk_level | 사용자 위험 성향 | conservative, normal, aggressive |
| created_at | 등록일 | 2026-04-28 |
| updated_at | 수정일 | 2026-04-28 |

### 계산 필드

`total_invested_amount`는 다음 공식으로 계산할 수 있다.

```text
total_invested_amount = average_price * quantity
```

`loss_rate`는 다음 공식으로 계산할 수 있다.

```text
loss_rate = ((current_price - average_price) / average_price) * 100
```

### 사용자 위험 성향

위험 성향은 판단 결과를 완전히 바꾸기보다는 제안 예산과 문구에 영향을 주는 보조 값으로 사용한다.

| risk_level | 의미 | 적용 방향 |
|---|---|---|
| conservative | 보수적 | 제안 예산 축소, 더 강한 조건 요구 |
| normal | 일반 | 기본 기준 적용 |
| aggressive | 공격적 | 제안 예산은 높일 수 있으나 위험 필터는 동일 적용 |

중요한 점은 공격적 성향이라도 치명적 위험 이벤트가 있으면 D 등급을 피할 수 없다는 것이다.

## 4.3 종목 기본 정보 데이터

종목 기본 정보는 주식 코드와 시장 구분, 섹터 등을 관리한다.

| 필드 | 설명 | 예시 |
|---|---|---|
| code | 종목 코드 | 005930 |
| name | 종목명 | 삼성전자 |
| market | 시장 구분 | KOSPI, KOSDAQ |
| sector | 업종 | 반도체 |
| is_active | 사용 여부 | true |

종목 기본 정보는 다음 목적에 사용된다.

```text
1. 사용자 보유 종목과 가격 데이터 연결
2. 시장 구분별 지수 비교
3. 섹터 확장 분석
4. 관리자 페이지에서 종목 관리
```

## 4.4 가격 데이터(OHLCV)

가격 데이터는 종목별 일봉 데이터를 의미한다.

| 필드 | 설명 |
|---|---|
| date | 거래일 |
| open_price | 시가 |
| high_price | 고가 |
| low_price | 저가 |
| close_price | 종가 |
| volume | 거래량 |
| change_rate | 등락률 |

### 필요 기간

| 분석 목적 | 필요 기간 |
|---|---|
| 단기 추세 | 최근 20거래일 |
| 중기 추세 | 최근 60거래일 |
| 장기 추세 | 최근 120~240거래일 |
| 지지선 판단 | 최근 60거래일 이상 |
| MA120 계산 | 최소 120거래일 |
| 변동성 분석 | 최소 14거래일 이상 |

### 가격 데이터 사용 목적

가격 데이터는 다음 판단에 사용된다.

```text
1. 현재가 산출
2. 손익률 계산
3. 이동평균 계산
4. RSI 계산
5. MACD 계산
6. ATR 계산
7. 지지선 탐색
8. 저점 갱신 여부 판단
9. 변동성 판단
```

### 데이터 품질 조건

가격 데이터는 날짜별로 중복되면 안 된다.

```text
unique(stock, date)
```

가격 데이터는 최신 거래일 기준으로 정렬 가능해야 한다.

```text
ordering = ["-date"]
```

## 4.5 기술적 지표 데이터

기술적 지표 데이터는 가격 데이터를 기반으로 계산되며, 저장하거나 요청 시 계산할 수 있다.

| 지표 | 목적 | 설명 |
|---|---|---|
| MA5 | 단기 반등 확인 | 최근 5거래일 종가 평균 |
| MA20 | 단기 추세 기준 | 최근 20거래일 종가 평균 |
| MA60 | 중기 추세 기준 | 최근 60거래일 종가 평균 |
| MA120 | 장기 추세 기준 | 최근 120거래일 종가 평균 |
| RSI14 | 과매도 판단 | 14일 기준 상대강도지수 |
| MACD | 추세 전환 판단 | 단기 EMA와 장기 EMA 차이 |
| MACD Signal | MACD 신호선 | MACD의 이동평균 |
| ATR14 | 변동성 판단 | 14일 평균 실제 변동폭 |
| Volume MA20 | 거래량 기준 | 최근 20일 평균 거래량 |
| Bollinger Band | 과매도·변동성 보조 | MA20 기준 상하단 밴드 |

### 이동평균 사용 기준

이동평균은 다음 판단에 사용된다.

```text
현재가 > MA5
MA5 상승 전환
현재가가 MA20 근처 회복
MA5 > MA20 여부
MA20 기울기 둔화 여부
MA20, MA60 하락 지속 여부
```

### RSI 사용 기준

RSI는 과매수·과매도 판단에 사용한다.

| RSI 구간 | 의미 | 기본 점수 방향 |
|---|---|---|
| 30 이하 | 과매도 | 가산 가능 |
| 30~45 | 약세지만 반등 가능 | 소폭 가산 |
| 45~60 | 중립 | 중립 |
| 70 이상 | 과열 | 감점 |

주의할 점은 RSI가 낮다고 해서 무조건 좋은 구간은 아니라는 것이다.

하락 추세에서는 RSI가 낮은 상태로 오래 머물 수 있으므로, RSI는 반드시 추세와 함께 해석해야 한다.

### MACD 사용 기준

MACD는 추세 전환 가능성을 판단하는 보조 지표다.

긍정 신호 예시는 다음과 같다.

```text
MACD가 Signal을 상향 돌파
MACD 음수 구간에서 상승 전환
히스토그램이 개선
```

부정 신호 예시는 다음과 같다.

```text
MACD가 Signal 아래 유지
MACD가 계속 하락
반등 실패 후 재하락
```

### ATR 사용 기준

ATR은 변동성과 손절 기준 계산에 사용한다.

```text
stop_loss_price = support_price - ATR14
```

또는 보수적으로 다음과 같이 사용할 수 있다.

```text
stop_loss_price = current_price - (ATR14 * 1.5)
```

## 4.6 지지선 데이터

지지선은 별도 입력 데이터라기보다 가격 데이터에서 계산되는 분석 결과다.

지지선은 최근 60거래일 또는 그 이상의 데이터에서 반복적으로 반등한 가격대를 탐색하여 계산한다.

### 지지선 판단에 필요한 데이터

```text
최근 60일 저가
최근 60일 종가
반등 발생 구간
거래량 증가 여부
현재가와 지지선의 거리
```

### 지지선 판단 기준

| 조건 | 점수 방향 |
|---|---|
| 현재가가 지지선 ±3% 이내 | 가산 |
| 지지선에서 거래량 증가 | 가산 |
| 지지선을 이탈 | 강한 감점 |
| 지지선 이탈 후 회복 | 소폭 가산 |
| 지지선 없이 저점 계속 갱신 | 감점 |

## 4.7 거래량 데이터

거래량은 가격 움직임의 신뢰도를 판단하는 핵심 보조 데이터다.

### 필요한 거래량 데이터

```text
일별 거래량
최근 20일 평균 거래량
하락일 거래량
반등일 거래량
지지선 부근 거래량
```

### 거래량 해석 기준

| 조건 | 의미 | 점수 방향 |
|---|---|---|
| 거래량이 20일 평균 대비 150% 이상 | 관심 증가 | 가산 가능 |
| 하락 중 거래량 급증 후 가격 방어 | 매도 물량 소화 가능성 | 가산 |
| 반등 시 거래량 증가 | 반등 신뢰도 증가 | 가산 |
| 하락 시 거래량 증가 | 매도 압력 증가 | 감점 |
| 반등 시 거래량 부족 | 반등 신뢰도 낮음 | 감점 |

거래량은 가격과 함께 해석해야 한다.

```text
거래량 증가 + 가격 상승 = 긍정 가능성
거래량 증가 + 가격 하락 = 부정 가능성
거래량 급증 + 가격 방어 = 매도 물량 소화 가능성
```

## 4.8 수급 데이터

수급 데이터는 투자 주체별 순매수/순매도를 의미한다.

| 필드 | 설명 |
|---|---|
| foreign_net_buy | 외국인 순매수 |
| institution_net_buy | 기관 순매수 |
| individual_net_buy | 개인 순매수 |
| program_net_buy | 프로그램 순매수 |

### 분석 기간

기본 분석 기간은 최근 5거래일이다.

필요 시 다음 기간도 확장 가능하다.

```text
최근 3거래일
최근 5거래일
최근 20거래일
```

### 수급 해석 기준

| 조건 | 의미 | 점수 방향 |
|---|---|---|
| 외국인 순매수 3일 이상 | 외국인 수급 개선 | 가산 |
| 기관 순매수 3일 이상 | 기관 수급 개선 | 가산 |
| 외국인+기관 동시 순매수 | 강한 긍정 신호 | 가산 |
| 외국인+기관 동시 순매도 | 강한 부정 신호 | 감점 |
| 개인만 강한 순매수 | 개인 물림 가능성 | 소폭 감점 |

주의할 점은 개인 순매수가 항상 나쁜 것은 아니지만, 하락 추세에서 개인만 강하게 매수하고 외국인·기관이 매도하는 구조는 위험 신호로 본다.

## 4.9 시장 데이터

시장 데이터는 개별 종목 판단보다 우선할 수 있다.

필요한 시장 데이터는 다음과 같다.

| 데이터 | 설명 |
|---|---|
| KOSPI index | 코스피 시장 흐름 |
| KOSDAQ index | 코스닥 시장 흐름 |

| S&P500 | 미국 대표 지수 |
| Nasdaq | 기술주 중심 지수 |
| 금리 관련 데이터 | 필요 시 확장 |

### 시장 데이터 사용 목적

시장 데이터는 다음 판단에 사용된다.

```text
1. 시장 전체 상승/하락 판단
2. 종목 하락이 개별 문제인지 시장 문제인지 구분
3. 환율 급등에 따른 외국인 수급 위험 판단
4. 글로벌 증시 급락에 따른 리스크 조정
```

### 시장 흐름 해석 기준

| 조건 | 점수 방향 |
|---|---|
| 코스피/코스닥이 20일선 위 | 가산 |
| 시장 지수가 반등 중 | 가산 |
| 시장 급락 중 | 강한 감점 |
| 환율 급등 | 감점 |
| 미국 나스닥 급락 | 감점 |

시장 전체가 급락하는 경우, 개별 종목의 기술적 지표가 양호해 보여도 등급을 낮출 수 있다.

## 4.10 뉴스/공시 리스크 데이터

뉴스와 공시는 위험 판단에서 가장 높은 우선순위를 가진다.

### 필요한 데이터

| 데이터 | 설명 |
|---|---|
| 최근 뉴스 | 악재/호재 분석 |
| 공시 | 실적, 유상증자, 감자, 횡령, 상폐 위험 |
| 실적 발표 | 매출, 영업이익, 순이익 |
| 리포트 | 목표가, 투자의견 |
| 거래소 공지 | 관리종목, 거래정지, 상장폐지 등 |

### 위험 키워드

```text
상장폐지
관리종목
감사의견 거절
의견거절
한정의견
거래정지

감자
횡령
배임
실적 악화
적자 전환
영업손실

회생절차

```

### 위험 수준 분류

| 위험 수준 | 예시 | 처리 |

| high | 감자, 횡령, 관리종목, 자본잠식 | C 또는 D |
| medium | 실적 부진, 목표가 하향, 대규모 유상증자 | 감점 |
| low | 단기 수급 이슈, 일반 뉴스 | 참고 |

뉴스/공시 리스크는 기술적 점수보다 우선한다.

예를 들어 RSI가 25이고 지지선 근처에 있더라도, 거래정지 공시가 있으면 D 등급이어야 한다.

# 5. 데이터 우선순위

## 5.1 데이터 중요도

모든 데이터가 동일한 중요도를 갖지 않는다.

중요도는 다음과 같이 본다.

| 우선순위 | 데이터 | 설명 |
|---|---|---|
| 1 | 뉴스/공시 리스크 | 치명적 위험 차단 |
| 2 | 시장 데이터 | 전체 리스크 환경 판단 |
| 3 | 가격/추세 데이터 | 종목 흐름 판단 |
| 4 | 지지선/거래량 | 반등 가능성 보조 판단 |
| 5 | 수급 데이터 | 투자 주체 흐름 판단 |
| 6 | 손실률 | 사용자 상태 판단 |
| 7 | 추가 예산 | 실행 가능성 판단 |

---

## 5.2 데이터 충돌 시 판단 기준

데이터가 서로 다른 방향을 가리킬 수 있다.

예를 들어 다음과 같은 상황이 가능하다.

```text
RSI는 과매도
하지만 시장은 급락 중

지지선 근처
하지만 외국인·기관 동시 순매도

거래량 증가
하지만 가격은 장대 음봉

손실률 -25%
하지만 회사에 구조적 악재 발생
```

이 경우 판단 기준은 다음과 같다.

```text
위험 이벤트 > 시장 흐름 > 종목 추세 > 지지선/거래량 > 수급 > 손실률
```

즉, 좋은 지표 하나만으로 전체 판단을 긍정적으로 바꾸면 안 된다.

# 6. 판단 방식 개요

## 6.1 점수 기반 시스템

시스템은 각 요소를 점수화하여 총점을 산출한다.

기본 구조는 다음과 같다.

```text
총점 = 추세 점수
     + 지지선 점수
     + 거래량 점수
     + 수급 점수
     + 시장 점수
     + 뉴스/공시 리스크 점수
```

뉴스/공시 리스크 점수는 음수일 수 있다.

또한 critical risk가 있을 경우에는 점수 계산을 중단하고 바로 D 등급을 반환한다.

---

## 6.2 기본 점수 구조

| 항목 | 최대 점수 또는 범위 |
|---|---|
| 추세 | 25 |
| 지지선 | 20 |
| 거래량 | 20 |
| 수급 | 20 |
| 시장 흐름 | 15 |
| 뉴스/공시 리스크 | -50 ~ 0 |

총점은 일반적으로 0~100 사이를 목표로 하되, 감점 조건에 따라 0 미만이 될 수 있다.

구현 시에는 최종 점수를 0~100 사이로 보정할 수 있다.

```text
final_score = max(0, min(100, raw_score))
```

---

## 6.3 등급 변환 기준

| 점수 | 등급 | 의미 |
|---|---|---|
| 75 이상 | A | 추가 매수 가능성 검토 구간 |
| 55~74 | B | 관찰 구간 |
| 35~54 | C | 물타기 금지 구간 |
| 34 이하 | D | 손절 또는 비중 축소 기준 점검 구간 |

---

## 6.4 손실률 기준

손실률은 단독으로 판단하지 않는다.

하지만 사용자 상태를 이해하고 제안 문구를 조정하는 데 사용한다.

| 손실률 | 기본 해석 |
|---|---|
| 0% ~ -5% | 물타기 필요성이 낮음 |
| -5% ~ -10% | 관찰 구간 |
| -10% ~ -20% | 1차 검토 가능 구간 |
| -20% ~ -30% | 신중한 검토 필요 |
| -30% 이하 | 위험 구간, 강한 근거 필요 |

주의할 점은 다음과 같다.

```text
손실률이 크다고 해서 물타기 구간은 아니다.
손실률이 작다고 해서 안전한 것도 아니다.
하락 원인과 현재 리스크 상태가 더 중요하다.
```

---

## 6.5 추가 매수 예산 계산 개요

추가 매수 예산은 사용자의 `max_additional_budget`을 기준으로 계산한다.

등급별 기본 제안은 다음과 같다.

| 등급 | 제안 예산 방향 |
|---|---|
| A | 추가 예산의 일부를 분할 매수 검토 |
| B | 소액 또는 관찰 유지 |
| C | 추가 매수 중단 |
| D | 추가 매수 금지, 손절 기준 점검 |

A 등급이라고 하더라도 전체 예산을 한 번에 사용하지 않는다.

기본 분할 매수 예시는 다음과 같다.

| 단계 | 조건 | 예산 비중 |
|---|---|---|
| 1차 | 지지선 확인 | 30% |
| 2차 | 저점 상승 확인 | 30% |
| 3차 | MA20 회복 확인 | 40% |

---

## 6.6 손절 기준 계산 개요

손절 기준은 다음 데이터를 활용할 수 있다.

```text
지지선
ATR14
현재가
평균 매입 단가
추가 매수 가격
```

예시 기준은 다음과 같다.

```text
1. 지지선 재이탈 시 손절 기준 점검
2. 추가 매수 후 -7% 하락 시 손절 기준 점검
3. ATR 기준 변동성 손절가 도달 시 손절 기준 점검
4. 악재 공시 발생 시 즉시 재평가
```

손절 기준 역시 “매도하라”가 아니라 “손절 기준 점검이 필요하다”로 표현해야 한다.

# 10. 최종 요약

이 시스템은 “수익을 예측하는 서비스”가 아니라 “추가 매수 위험도를 판단하는 서비스”다.

핵심 질문은 다음과 같다.

```text
지금 이 종목을 추가 매수해도 되는 상태인가?
아니면 손실 확대 위험이 더 큰 상태인가?
```

핵심 우선순위는 다음과 같다.

```text
1. 위험 이벤트 차단
2. 시장 흐름 확인
3. 종목 추세 확인
4. 지지선과 거래량 확인
5. 수급 확인
6. 분할 매수 가능성 검토
7. 손절 기준 제시
```

모든 구현 단계는 이 원칙을 기준으로 진행한다.
