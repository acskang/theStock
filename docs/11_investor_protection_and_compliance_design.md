# 11_investor_protection_and_compliance_design.md

# theStock 투자자 보호 및 준법 표현 설계서

---

# 0. 문서 목적

`theStock`는 사용자의 보유 종목에 대해 물타기, 관망, 손절, 추가 매수 한도 등을 계산해 보여주는 서비스다.

이 기능은 사용자에게 큰 도움을 줄 수 있지만, 동시에 다음 오해를 만들 수 있다.

```text
1. 서비스가 매수/매도를 추천한다고 오해
2. 확률값을 수익 보장으로 오해
3. 추가 매수 한도를 추천 매수 금액으로 오해
4. 손절 기준을 확정적 지시로 오해
5. 데이터 오류나 지연이 없는 것으로 오해
```

이 문서는 이러한 오해를 줄이고, 투자자 보호 관점에서 화면/API/문서/로그에 적용해야 할 표현 원칙을 정의한다.

이 문서는 법률 자문이 아니라 제품 설계 기준이다.  
운영 전에는 필요한 경우 별도 법률 검토가 필요하다.

# 1. 최상위 원칙

## 1.1 투자 권유 금지

`theStock`의 모든 결과는 다음 성격을 가진다.

```text
데이터 기반 참고 정보
```

다음 성격으로 표현하면 안 된다.

```text
투자 권유
매수 추천
매도 추천
수익 보장
손실 회피 보장
```

## 1.2 최종 판단 책임

모든 컨설팅 화면과 주요 API 설명에는 다음 원칙이 반영되어야 한다.

```text
최종 투자 판단과 그 결과에 대한 책임은 사용자 본인에게 있습니다.
```

## 1.3 데이터 한계 고지

시장 데이터는 지연, 누락, 오류, 보정 이슈가 있을 수 있다.

필수 고지:

```text
본 결과는 제공된 데이터와 수집 시점 기준으로 계산된 참고 정보입니다.
데이터 지연, 누락, 오류 또는 시장 급변에 따라 실제 결과와 다를 수 있습니다.
```

# 2. 금지 표현

다음 표현은 화면, API message, 이메일, 리포트, 문서에서 사용하지 않는다.

## 2.1 매수 지시 표현

금지:

```text
지금 매수하세요.
추가 매수하세요.
물타기하세요.
지금 사도 됩니다.
매수 적기입니다.
강력 매수 구간입니다.
```

대체:

```text
추가 매수 검토 가능 조건 중 일부가 충족되었습니다.
현재 데이터 기준으로 추가 매수 리스크가 상대적으로 낮게 평가됩니다.
다만 최종 판단 전 리스크 조건을 확인해야 합니다.
```

## 2.2 매도 지시 표현

금지:

```text
지금 매도하세요.
손절하세요.
반드시 팔아야 합니다.
더 떨어질 것이므로 매도해야 합니다.
```

대체:

```text
현재 데이터 기준으로 손실 확대 위험이 높게 평가됩니다.
손절 기준을 사전에 검토할 필요가 있습니다.
추가 매수보다는 리스크 축소 검토가 우선입니다.
```

## 2.3 수익 보장 표현

금지:

```text
수익 가능성이 높습니다.
회복이 확실합니다.
반등할 가능성이 큽니다.
손실을 만회할 수 있습니다.
```

대체:

```text
목표가 도달 가능성이 상대적으로 높게 추정됩니다.
과거 유사 조건 기준의 조건부 추정값입니다.
실제 수익을 보장하지 않습니다.
```

## 2.4 공포 조장 표현

금지:

```text
곧 폭락합니다.
망할 가능성이 큽니다.
절대 사면 안 됩니다.
큰일 납니다.
```

대체:

```text
현재 리스크 이벤트가 감지되어 보수적인 판단이 필요합니다.
데이터 기준으로 추가 손실 위험이 높게 평가됩니다.
```

# 3. 허용 표현 가이드

## 3.1 판단 결과 표현

권장 레이블:

```text
검토 가능
보류 권장
추가 매수 부적합
리스크 높음
데이터 부족
판단 보류
```

사용을 피할 레이블:

```text
매수
강력 매수
매도
강력 매도
수익 확실
```

## 3.2 추가 매수 금액 표현

`capital_plan`에서 계산되는 금액은 추천 매수 금액이 아니다.

권장 표현:

```text
추가 매수 참고 한도
리스크 한도 내 검토 가능 금액
손실 한도를 넘지 않기 위한 계산상 한도
```

금지 표현:

```text
추천 매수 금액
사야 할 금액
적정 매수 금액
```

## 3.3 확률 표현

권장 표현:

```text
조건부 추정 확률
현재 데이터 기준 추정값
과거 유사 조건 기반 참고값
```

금지 표현:

```text
실제 수익 확률
성공 확률 확정값
목표가 도달 보장 확률
```

# 4. 화면별 고지 정책

## 4.1 첫 진입 화면

필수 고지:

```text
본 서비스는 투자 판단을 돕기 위한 데이터 기반 참고 정보를 제공합니다.
특정 종목의 매수·매도 권유가 아니며, 최종 투자 판단과 책임은 사용자 본인에게 있습니다.
```

## 4.2 보유 종목 입력 화면

필수 고지:

```text
입력한 평균 단가와 보유 수량에 따라 계산 결과가 달라집니다.
잘못된 입력값은 부정확한 결과를 만들 수 있습니다.
```

## 4.3 컨설팅 결과 화면

필수 고지:

```text
아래 결과는 현재 수집된 데이터 기준의 참고 분석입니다.
시장 급변, 공시, 거래정지, 데이터 지연 등에 따라 실제 투자 결과와 다를 수 있습니다.
```

## 4.4 확률 상세 화면

필수 고지:

```text
표시된 확률은 과거 유사 조건과 현재 데이터에 기반한 조건부 추정값입니다.
미래 주가를 보장하거나 예측하는 확정값이 아닙니다.
```

## 4.5 고위험 결과 화면

필수 고지:

```text
현재 데이터 기준으로 리스크가 높게 평가되었습니다.
추가 매수 판단보다 손실 확대 가능성, 자금 비중, 투자 기간을 먼저 점검해야 합니다.
```

# 5. API 응답 문구 정책

컨설팅 API 응답에는 사람이 읽는 message와 machine-readable code를 분리한다.

예:

```json
{
  "decision_code": "HOLD_REVIEW_REQUIRED",
  "decision_label": "보류 권장",
  "summary_message": "현재 데이터 기준으로 추가 매수보다 리스크 점검이 우선입니다.",
  "disclaimer": "본 결과는 투자 권유가 아닌 참고 정보입니다."
}
```

주의:

```text
프론트엔드에서 임의로 '매수 추천' 같은 문구로 바꾸지 않도록 label 정책을 중앙화한다.
```

# 6. 사용자 동의 정책

## 6.1 최초 사용 동의

최초 컨설팅 실행 전 다음 동의를 받는다.

```text
1. 본 서비스는 투자 권유가 아니라 참고 정보임을 이해했습니다.
2. 최종 투자 판단과 책임은 본인에게 있음을 이해했습니다.
3. 데이터 지연, 오류, 누락 가능성이 있음을 이해했습니다.
4. 입력한 보유 종목 정보가 컨설팅 결과 계산에 사용됨을 이해했습니다.
```

## 6.2 동의 기록

저장 항목:

```text
user
agreement_version
agreed_at
ip_hash 또는 request metadata 최소값
user_agent_hash 선택
```

원문 IP나 과도한 개인정보 저장은 피한다.

## 6.3 약관 버전

고지 문구가 바뀌면 agreement_version을 올린다.

```text
INVESTOR_NOTICE_V1
INVESTOR_NOTICE_V2
```

# 7. 고위험 이벤트 처리

다음 이벤트가 감지되면 컨설팅 결과를 보수화하거나 차단한다.

```text
1. 거래정지
2. 상장폐지 사유 발생
3. 관리종목
4. 투자주의/투자경고/투자위험
5. 감사의견 거절/한정
6. 대규모 유상증자
7. 횡령/배임 공시
8. 불성실공시
9. 급격한 거래량 이상
10. 가격제한폭 근접 급락
```

권장 결과:

```text
추가 매수 판단 중단
리스크 이벤트 확인 우선
컨설팅 결과 confidence 하향
고위험 경고 배너 노출
```

# 8. 데이터 품질과 투자자 보호 연결

데이터 품질이 낮은 경우 결과를 약하게 표현해야 한다.

| 데이터 품질 | 컨설팅 처리 | 표현 |
|---|---|---|
| A | 정상 제공 | 현재 데이터 기준 참고 분석 |
| B | 정상 제공 + 경고 | 일부 데이터 지연 가능 |
| C | 제한 제공 | 판단 신뢰도 제한 |
| D | 강한 경고 | 추가 판단 전 데이터 확인 필요 |
| F | 제공 제한 | 현재 데이터로 판단 불가 |

금지:

```text
데이터 품질 F 상태에서 추가 매수 참고 한도 제공
```

저장 권장:

```text

```

주의:

```text

```

# 10. 리포트/PDF/이메일 표현 원칙

리포트 생성 기능을 추가할 경우 첫 페이지와 마지막 페이지에 고지를 넣는다.

필수 문구:

```text
본 리포트는 투자 권유, 매수·매도 추천, 수익 보장을 목적으로 하지 않습니다.
제공된 수치와 확률은 데이터 기반 참고 정보이며, 최종 투자 판단과 책임은 사용자 본인에게 있습니다.
```

PDF 파일명에도 과도한 표현을 쓰지 않는다.

권장:

```text
thestock_consulting_report_YYYYMMDD.pdf
```

금지:

```text
buy_recommendation.pdf
profit_strategy.pdf
```

# 11. 운영자/관리자 화면 주의

관리자 화면에서도 다음 원칙을 지킨다.

```text
1. 사용자의 평균 단가/수량/투자금은 기본 마스킹
2. staff가 상세 조회할 때 감사 로그 기록
3. 컨설팅 결과를 수동 조작하지 않음
4. 기준 데이터 수정 시 변경 이력 기록
```

# 12. 구현 체크리스트

```text
[ ] 공통 disclaimer 문구 상수화
[ ] 화면별 고지 컴포넌트 추가
[ ] API 응답 disclaimer 필드 추가 또는 문서화
[ ] decision label에서 매수/매도 추천 표현 제거
[ ] capital_plan 표현을 '추천 금액'이 아닌 '참고 한도'로 변경
[ ] probability 설명 문구 추가
[ ] 최초 사용 동의 모델 추가 검토
[ ] 고위험 이벤트 시 컨설팅 제한 처리
[ ] 데이터 품질 F일 때 컨설팅 제한 처리
[ ] 리포트 생성 시 고지 문구 포함
[ ] staff 조회 감사 로그 추가
```

# 13. Codex 작업 지시 요약

```text
theStock의 컨설팅 결과가 투자 권유로 오해되지 않도록 화면/API/문구를 보강한다.
'매수하세요', '추천 매수 금액', '수익 가능성이 높다' 같은 표현을 제거한다.
추가 매수 금액은 '리스크 한도 내 참고 금액'으로 표현한다.
확률은 '조건부 추정값'으로 설명한다.
데이터 품질이 낮거나 고위험 이벤트가 있으면 컨설팅 결과를 제한하거나 강한 경고를 노출한다.
기존 API 구조는 가능한 유지하되 disclaimer/notice 필드를 추가할 때 하위 호환성을 고려한다.
```

# 14. 결론

`theStock`의 핵심 가치는 사용자가 감정적으로 물타기하지 않도록 돕는 것이다.

하지만 표현을 잘못하면 서비스가 투자 권유처럼 보일 수 있다.  
따라서 모든 화면과 API는 다음 원칙을 따라야 한다.

```text
1. 판단을 돕되 지시하지 않는다.
2. 확률을 보여주되 보장하지 않는다.
3. 한도를 계산하되 추천 금액이라고 말하지 않는다.
4. 위험을 경고하되 공포를 조장하지 않는다.
5. 최종 책임은 사용자에게 있음을 명확히 알린다.
```
